# @tokenisation/pack-travel

Travel vertical package for tokenisation SDK -- airline tickets, hotel reservations, car rentals, concert tickets.

## Installation

```bash
npm install @tokenisation/pack-travel
```

## Usage

```ts
import { } from '@tokenisation/pack-travel';
```

## Documentation

See the main [TokenisationSDK documentation](https://docs.ahoy.fund/sdk) for full API reference and guides.
