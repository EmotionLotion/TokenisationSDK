# Infrastructure

Supporting infrastructure, tooling, and reference applications. Not part of the SDK itself.

| Directory | Contents |
|-----------|----------|
| `apps/` | Reference applications (real estate demo) |
| `circuits/` | ZKP circuits (Circom) |
| `cre/` | Compliance runtime engine |
| `demo/` | Mock demos (Comet) |
| `deploy/` | Kubernetes, Terraform, Helm charts |
| `docker/` | Docker Compose, Grafana, Prometheus, Loki |
| `e2e/` | End-to-end Playwright tests |
| `functions/` | Chainlink Functions scripts |
| `policies/` | JSON policy definitions |
| `scripts/` | Build and deployment scripts |
| `tests/` | API and conformance tests |
| `website/` | Documentation site (Docusaurus) |

These are used for deployment, monitoring, and testing infrastructure.
The SDK packages live in the root `packages/` directory.
